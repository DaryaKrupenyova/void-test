# Баги

Проверяла добавление услуг, повторное добавление, изменение количества и удаление строк.

## 1. Состояние не сохранялось между рендерами

`selectedServices`, `selectedServiceId` и `quantity` были обычными переменными `let`. При изменении они не вызывали перерисовку, а при следующем рендере получали начальные значения.

Исправила на `useState`. Итоговую сумму считаю из списка услуг при каждом рендере.

Для `select` храню id строкой, а в `find` преобразую его в число, чтобы сравнение работало корректно.

## 2. Мутация массива и объектов

`push`, `splice` и `existing.quantity += quantity` изменяли исходный массив и объекты. React может не заметить такие изменения, поскольку ссылка на состояние остаётся прежней.

Исправила на иммутабельные операции: `map` для изменения количества, `filter` для удаления и создание нового массива при добавлении.

## 3. Сравнение услуг по ссылке

`item.service === service` сравнивает ссылки на объекты, а не сами услуги. При разных объектах одной услуги проверка не сработает.

Исправила сравнение на `item.service.id === service.id`.

## 4. Некорректное количество

Атрибуты `min` и `max` не запрещают полностью очистить поле или ввести некорректное для задачи значение. Из-за этого в расчётах могли появляться ноль, дробные числа или `NaN`.

Добавила проверку: количество должно быть целым числом от 1 до 10. Кнопка добавления недоступна, пока значение некорректно.
